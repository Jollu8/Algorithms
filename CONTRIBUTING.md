# Добавление материалов

1. Выберите раздел: `algorithms/<тема>/` для алгоритма, `cpp/<тема>/` для
   примера C++, `problems/<площадка>/` для задачи, `libraries/` для библиотечного
   модуля. Незавершённые наброски складывайте в `playground/`.
2. Для новых каталогов и файлов используйте английские имена в `snake_case`.
   Исторические имена сохранены, чтобы не смешивать перенос с переименованием всего кода.
3. В начале примера опишите назначение, требования к входу, сложность по времени
   и памяти. Укажите, какие граничные случаи проверены.
4. Для задачи добавьте рядом `README.md` с условием или ссылкой, форматом ввода
   и вывода и объяснением решения. Входные данные храните рядом в `tests/`.
5. Соберите самостоятельный пример через `ALGORITHM_SOURCE`, как описано в
   [инструкции](docs/building.md). Готовый пример можно добавить явным вызовом
   `add_algorithm` в корневой `CMakeLists.txt`; имя цели должно быть уникальным.
6. Добавьте ссылку в [каталог](docs/catalog.md). При переносе обновляйте ссылки,
   пути CMake и относительные `#include`.

Для форматирования и статического анализа в корне есть `.clang-format`
и `.clang-tidy`. Проверки алгоритма должны учитывать пустой ввод, минимальный
размер, повторяющиеся значения и другие случаи, существенные для задачи.
