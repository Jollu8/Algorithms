## Быстрый старт

Нужны CMake 3.27+ и компилятор с поддержкой C++20.
Базовые примеры собираются без внешних зависимостей.

```sh
cmake -S . -B build/debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build/debug --parallel
./build/debug/sorting_insertion
```

По умолчанию собираются девять самостоятельных примеров сортировки.
Компиляция примера не означает, что алгоритм проверен на всех граничных случаях.
Другие материалы можно изучать через каталог и собирать отдельно по [инструкции](docs/building.md).
