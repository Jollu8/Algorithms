# Библиотечные эксперименты

| Модуль | Назначение |
| --- | --- |
| [data_structures](data_structures/) | AVL-дерево, бинарная куча, массив и тесты |
| [containers](containers/) | Списки, вектор, очереди и тесты |
| [tools](tools/) | Логирование, вспомогательные функции и прежние инструменты сборки |

Здесь сохранена прежняя библиотечная инфраструктура, включая Conan,
CMake и GoogleTest. Она не входит в корневую сборку и требует отдельного
восстановления: существуют два дерева заголовков (`enjo` и `libs`), взаимные
зависимости `tools` и `containers`, а рецепт Conan содержит устаревшие настройки.
Существующие тесты лежат в подкаталогах `test/`; корневая сборка их не запускает.

Исходный код и тесты сохранены для дальнейшей работы. Самостоятельные
примеры алгоритмов собираются по [основной инструкции](../docs/building.md).
